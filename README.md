# Image Sharing Platform

A full-stack image sharing web application built with **HTML, CSS, JavaScript, Node.js, Express, and MongoDB**.

A portfolio project focused on authentication, image uploads, user interactions, and responsive design.

---

## Features

- User registration and login
- JWT authentication
- Upload and delete images
- Like and unlike images
- Follow and unfollow users
- View followed channels
- Drag & Drop image uploads
- Responsive design
- Automatic login with stored JWT

---

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript (ES6 Modules)

### Backend
- Node.js
- Express.js
- MongoDB & Mongoose
- JWT
- Multer for image uploads
- bcrypt for password hashing

---

## Main Functionality

### Authentication
- User registration and login
- Secure password hashing

### Image Sharing
Users can:
- Upload images
- Delete their uploads
- Like and unlike images

### Social Features
Users can:
- Follow other users
- View followed channels
- Browse images from creators

---

## Responsive Design

The application adapts to different screen sizes, including:

- Navigation
- Image galleries
- Forms
- Upload interface

---

## Security

- Passwords hashed with bcrypt
- JWT authentication for protected actions
- Authorization checks to ensure users can only modify their own content
